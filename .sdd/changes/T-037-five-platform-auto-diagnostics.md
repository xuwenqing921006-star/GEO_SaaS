# T-037 五平台自动 GEO 诊断

## 变更目标

把 GEO 诊断从“先建立问题集、选择平台、人工粘贴样本，再回到诊断页评分”
简化为一次操作：

1. 系统从当前企业知识库提取企业名称、所在地区、主营服务和主要客群。
2. 自动形成品类发现、推荐决策和品牌核验三类检测问题。
3. 固定检测 DeepSeek、豆包、腾讯元宝、通义千问和 Kimi。
4. 自动分析回答中的品牌出现、地区与主营关联、推荐命中、可核验事实和来源。
5. 展示单平台评分、等级、评语、检测问题与 GEO 优化建议。

## 评分规则

- 品类问题中的品牌出现：30 分。
- 地区和主营业务正确关联：25 分。
- 推荐问题中进入推荐结果：25 分。
- 回答包含可由知识库核验的企业事实：15 分。
- 回答显示可见来源或链接：5 分。
- 85—100 为“优”，70—84 为“良”，50—69 为“中”，0—49 为“差”。
- 未配置、请求失败和无有效回答不按 0 分计算，也不进入综合平均。

## 平台与产品边界

- 页面只保留 DeepSeek、豆包、腾讯元宝、通义千问和 Kimi。
- 百度 AI 搜索、夸克 AI、微信 AI 搜索、抖音 AI 搜索、纳米 AI 搜索退出目录。
- 旧监测页从主导航移除，旧地址跳转到 GEO 诊断。
- 豆包、腾讯元宝和 Kimi 通过服务端官方 API 配置接入；没有密钥时明确显示未配置。
- API 检测不伪装成消费者 App 的完全等价结果，页面显示对应口径说明。

## 接受标准

1. 点击一次“开始诊断”即可从知识库自动生成问题并检测五个平台。
2. 页面不存在人工样本、问题集、平台选择和管理平台检测入口。
3. 平台目录只返回五个平台，且均为 API 自动检测模式。
4. 未配置和失败平台不参与综合分，不显示伪造的 0 分。
5. 评分使用新的五项规则，并展示自动生成的检测问题与回答摘要。
6. 企业知识库更新后，旧诊断继续标记为过期并允许一键重新检测。

## 非范围

- 不自动登录或模拟操作第三方消费者端 App。
- 不承诺 API 回答与消费者 App 在所有时间完全一致。
- 不保证任何平台一定收录、引用或推荐客户。
- 不自动发布内容。
