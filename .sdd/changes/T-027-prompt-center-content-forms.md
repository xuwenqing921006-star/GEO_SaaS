# T-027 提示词中心、内容形式与渠道联系方式合规

## 变更目标

把当前硬编码的内容生成选项升级为可维护、可版本化的提示词模板体系。运营人员在
生成文章时选择内容形式，系统根据关键词意图、企业知识和目标发布渠道组合提示词，
并按渠道规则保留、弱化或移除手机号、微信、二维码和站外链接。

## 产品原则

1. GEO 可理解性是所有文章的基础质量要求，不单独作为一种固定模板。
2. 内容形式决定读者任务和文章结构，关键词只确定主题与用户问题。
3. 企业事实、联系方式和渠道规则由系统变量注入，不由运营人员复制到提示词。
4. 基础安全规则只读；业务母提示词、内容形式模块和关键词策略提示词可维护。
5. 模板修改只影响后续生成，历史文章保留当时的模板版本和事实快照。
6. 平台规则可能变化，联系方式策略必须保存核验状态和日期，不能宣称永久合规。

## 首版内容形式

- 本地推荐回答
- 选择决策指南
- 实用操作指南
- 服务项目说明
- 场景解决方案
- 高频问题 FAQ
- 门店与服务范围
- 品牌实体介绍
- 价格费用说明（需价格资料）
- 服务流程与保障（需流程或保障资料）
- 客观比较（不得编造竞品）
- 真实案例复盘（需真实案例资料）

## 提示词分层

```text
只读系统规则
+ 可维护通用母提示词
+ 可维护内容形式模块
+ 可维护渠道适配模块
+ 企业事实与用户问题变量
+ 输出结构
+ 独立质量复核
```

## 渠道联系方式策略

- `allow`：可按模板正常展示已确认的公开企业联系方式。
- `official_only`：只保留官网、平台主页或站内官方入口，不展示手机号、微信。
- `omit`：正文删除手机号、微信、二维码和外链，只使用中性站内行动提示。
- `manual_review`：默认删除直接联系方式并标记发布前复核。

所有默认规则采用保守策略；运营人员可在提示词中心查看规则依据、核验日期并修改
后续生成策略。任何修改不自动改写已经生成或发布的文章。

## 页面变更

### 内容工作台

- 内容形式从 5 个硬编码选项升级为模板目录。
- 支持“AI 智能组合”或手工选择一种内容形式。
- 选择目标渠道后显示联系方式处理结果。
- 文章列表展示内容形式和目标渠道。

### 关键词

- 主关键词与自然用户问题分开生成。
- 覆盖地区发现、推荐决策、品牌核验、服务了解、场景适配、比较选择、价格流程和
  信任保障等意图。
- 每条用户问题给出推荐内容形式，但允许生成时覆盖。
- 同一主题下问题语义去重，不强制每条都重复地区和主营词。

### 系统设置 / 提示词中心

- 展示内容生成、关键词策略和渠道适配模板。
- 支持编辑、保存新版本、启停、恢复系统默认和查看变量。
- 安全边界与内部标识隔离规则只读。
- 预览组合提示词不调用模型；真实试生成必须由用户主动触发。

## 非范围

- 不自动向第三方平台发布内容。
- 不代替平台的实时内容审核。
- 不保证平台允许某种联系方式，也不保证 AI 收录、引用或推荐。
- 不自动覆盖历史文章。

## 接受标准

1. 内容生成可选择内容形式，且不同形式使用不同、可维护的模板版本。
2. 提示词中心可编辑业务模板、恢复默认并查看版本；安全规则不可被覆盖。
3. 关键词生成覆盖完整用户意图并返回推荐内容形式。
4. 选择目标渠道后，正文联系方式按渠道策略处理，发布前可清楚看到处理结果。
5. 文章版本记录模板代码、模板版本、内容形式和目标渠道。
6. 批量生成无重复标题、无明显同构正文、无内部 ID、无关键词堆砌。
7. 仅使用本地 Mock 完成验收，不自动调用真实付费模型。
