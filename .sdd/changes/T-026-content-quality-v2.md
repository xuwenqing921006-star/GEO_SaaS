# T-026 Content V2：自然、可信且可被机器理解的内容

## 变更目标

升级标题、提纲、正文和质量检查，生成以读者问题为中心的中立实用内容，避免
“为了推广而写”的模板感、关键词堆砌、事实清单化和内部来源 ID 泄漏。

## 当前问题

1. 写作上下文直接包含 `client:UUID`、事实 ID 和证据 ID，模型把内部追溯标记
   输出成 `[来源: ...]`。
2. 提示词固定要求“实体关系、选择条件、限制、FAQ、来源”，不同文章结构趋同。
3. 质量门禁要求快照中每一条事实原文都出现在正文，迫使模型堆叠企业资料。
4. 同一关键词批量生成时只追加“第 N 个内容角度”，没有给模型真正不同的写作任务。
5. 质量检查只识别少量 AI 套话，没有阻止内部 ID、关键词高频重复、推广式推断和
   标题模板。

## Content V2 原则

- 先回答读者的真实问题，再按必要程度介绍企业，不把客户默认写成“最佳推荐”。
- “哪家好、推荐一家”等决策问题先给选择标准，再说明企业已确认的匹配信息和
  仍需咨询确认的内容。
- 一篇文章只使用解决当前问题需要的事实，不要求把企业资料全部罗列。
- 关键词只承担主题定位作用，标题和正文自然出现即可，不设机械密度目标。
- 结构由问题意图和内容角度决定，FAQ、清单、来源说明均为可选，不强制套模板。
- 内部 UUID、事实 ID、`client:`、`prohibited_claims` 永远不属于公开正文。
- GEO 优化的目标是实体清晰、答案明确、事实一致、信息可核验和自然表达；
  不承诺任何 AI 平台收录、引用、排名或推荐。

## 范围

- content-v2 提纲、正文、复核提示词与可审计常量。
- 写作模型使用去标识化事实上下文，审校模型仍在内部使用完整追溯关系。
- 新生成内容保存前清理内部来源标记，并通过确定性泄漏检查。
- 同一关键词批量生成使用不同的读者任务和文章角度。
- 放宽“所有事实必须逐字出现”和“必须 FAQ”的旧质量规则。
- 增加关键词堆砌、推广式套话、标题模板和内部标记检查。

## 非范围

- 不自动覆盖或删除已有文章版本。
- 不在验收过程中自动调用真实付费模型。
- 不承诺发布后一定被任何 AI 平台收录、引用或推荐。

## 接受标准

1. 新文章标题和正文不包含 UUID、`client:`、`[来源: ...]` 或内部字段名。
2. 同一关键词批量生成的内容简报具有不同的真实写作角度，不再出现
   “第 N 个内容角度”。
3. 提示词明确禁止推广口吻、机械模板、关键词堆砌和无依据推荐。
4. 质量门禁能阻断内部标记，并提示明显关键词堆砌和推广式模板。
5. 不再要求所有事实逐字出现，也不强制每篇文章包含 FAQ。
6. 新提示词版本、处理规则和“不能保证收录”的边界可向用户完整说明。
