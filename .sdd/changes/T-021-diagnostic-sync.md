# T-021 GEO 诊断与下游页面同步

## 目标

企业知识库简化和结构化分类后，GEO 诊断必须识别事实快照是否过期，五维结果
应来自当前企业事实、内容库存、来源记录和真实 AI 监测；关键词、内容、渠道页面
不能继续把过期诊断当作当前依据。

## 范围

- GEO 诊断 API 返回快照过期状态和变化数量。
- 企业实体、资料依据、问题内容、公开来源和 AI 可见性使用确定性真实数据计算。
- L0—L4 只根据真实 AI 监测样本得出。
- GEO 诊断、关键词计划、内容工作台和渠道建议显示过期提示并限制依赖旧诊断的
  新生成操作。
- 保留已有诊断、策略和文章作为历史记录，不自动覆盖。
- 清理页面中已经不符合简化知识库的审核、确认和授权文案。

## 非范围

- 不自动发布内容。
- 不推测搜索量、平台收录概率或推荐概率。
- 不删除或重写已有文章和历史诊断。
- 不增加新的客户角色、审核流或复杂发布回填。

## 验收标准

1. 知识事实、正文、版本或证据关系变化后，最新诊断返回过期状态和变化数量。
2. 过期诊断在 P03/P04/P05/P06 有明确提示，P04/P06 不允许基于旧诊断生成。
3. 五维分数不再固定为 100/100/0/0/null，而是读取当前事实、证据、内容、来源
   和监测；无数据时返回 `null`。
4. L1—L4 仅由已成功且已评估的真实监测样本计算；无样本保持 L0。
5. P03 不再显示“公开授权证据”等已经移除的审核式文案。
6. 受影响后端测试、前端单元测试、类型检查和构建通过。
