# T-060 移除 GEO 诊断基础渠道建议

## 目标

GEO 诊断不再在缺少来源信号时固定推荐百家号、搜狐号或网易号，避免把通用渠道清单误解为诊断结论。

## 范围

- 删除“无来源信号时补满三条渠道建议”的前端兜底逻辑。
- 只有本次 AI 回答来源中真实识别到支持的内容渠道时，才展示对应渠道动作。
- 没有渠道来源信号时，继续展示诊断产生的内容、事实和关键词优化建议。
- 渠道配置页面、渠道账号、自动发布及诊断评分不变。

## 验收标准

1. `channel_signals` 为空时，GEO 诊断不展示任何“基础渠道建议”。
2. 存在可识别的真实渠道来源信号时，仍可展示对应的“本次结果建议”。
3. 普通 GEO 优化建议、配置发布平台和生成关键词入口保持可用。
4. 前端格式、Lint、类型、单元测试与生产构建通过。

## 兼容与回滚

本次不改数据库和 API，仅删除前端无依据兜底。回滚时恢复 `buildChannelActionPlan` 的补齐分支即可。
