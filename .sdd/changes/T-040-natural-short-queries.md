# T-040 自然短查询生成

## 问题

知识库可能包含完整课程、产品和适用对象清单。直接把这些文本拼进诊断问题或
关键词，会形成普通消费者不会输入的长问题，并污染后续平台检测结果。

## 规则

1. 地区优先使用消费者常用简称，例如“即墨区”提炼为“即墨”。
2. 主营资料先归纳为一个核心品类，例如课程清单提炼为“少儿美术”。
3. 自动诊断固定形成品类发现、推荐决策和品牌核验三类短查询。
4. 关键词问题通常不超过 28 个汉字，每条只表达一个需求。
5. 含多项课程、产品、人群或年龄清单的模型结果直接过滤，并用安全模板补齐。
6. 场景措辞按行业选择，教育可使用“课程”，保洁、维修等行业使用通用服务措辞。

## 示例

- 即墨少儿美术
- 即墨少儿美术哪家好
- 请推荐一家即墨的少儿美术机构
- 莱恩美术怎么样

## 边界

- 知识库完整资料仍用于企业事实核验和文章写作，不因查询提炼而丢失。
- 查询精简不代表伪造搜索量或热度。
- 历史诊断快照不覆盖，重新诊断或重新生成关键词后使用新规则。
