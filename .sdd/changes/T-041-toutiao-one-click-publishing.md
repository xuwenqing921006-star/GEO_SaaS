# T-041 头条号一键发布与渠道配置

## 产品行为

1. 内容工作台分开显示生成状态和发布状态。
2. “标记已发布”改为“一键发布”，根据文章当前版本的目标渠道执行。
3. 首版只允许 `target_channel_id=toutiao` 的文章进入自动发布队列。
4. 渠道配置页提供头条号登录、连接检测和启停开关；其他平台只显示即将支持。

## 状态

- 生成状态：等待生成、生成中、生成完成、生成失败。
- 发布状态：未发布、等待发布、发布中、已发布、发布失败、需要登录、
  需要安全验证、平台拒绝。
- 旧文章发布记录在迁移后保留为已发布；编辑产生的新版本重新回到未发布。

## 自动发布边界

- 头条号长图文没有面向普通账号的公开文章发布 API，首版使用本机浏览器自动化。
- 首次登录由运营人员在专用可见浏览器窗口完成，系统不保存账号密码。
- 后续发布使用同一专用浏览器会话并在本机隐藏执行。
- 验证码、安全验证和登录过期不会绕过，任务转为可处理状态。
- 只有识别到发布成功、已提交或审核中回执时才记录已发布。

## 实现

- Alembic `0021` 扩展发布记录并新增渠道配置表。
- `content_publish` 独立 Worker 任务负责发布。
- Playwright 复用本机 Chrome/Edge 和专用 profile。
- 固定 Mock 只用于自动测试，不会触达外部平台。
