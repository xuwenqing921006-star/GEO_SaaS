# T-022 简化 GEO 诊断、关键词与内容生产闭环

## 变更目标

把当前偏专业流程的 GEO 工作台收敛为代运营人员容易理解的四步闭环：

1. 企业知识库只维护基础企业资料。
2. GEO 诊断展示真实 AI 平台可见表现、100 分评分、等级、评语和建议。
3. 关键词页面由 AI 生成可多选的主关键词、长尾问题、类型和用户意图。
4. 内容工作台根据所选关键词批量生成文章，并提供查看、编辑、复制、发布标记和删除。

## 关键业务规则

- 知识库负责定义企业实体和事实边界，不能单独证明企业已被 AI 平台收录。
- 平台表现只使用真实、成功且已评估的监测样本；未检测和检测失败不按 0 分处理。
- 平台评分满分 100：企业提及 30、正确关联 20、推荐命中 25、事实准确 15、
  稳定出现 10。
- 等级：优 80—100、良 60—79、中 40—59、差 0—39；无样本为未检测。
- 关键词类型为地区主营、企业品牌、推荐决策、场景适配、细分服务和比较信任。
- AI 关键词不得扩展知识库中不存在的地区、服务、资质、价格、效果或案例。
- 文章初稿全部由 AI 生成，必须切合所选关键词、用户意图和企业真实资料。
- 首版“发布”仍为人工发布工作流：复制内容并标记状态，不接入平台自动发布。

## 页面变更

### GEO 诊断

- 顶部展示综合评分、等级、已检测平台数、有效样本数和检测时间。
- 平台列表展示状态、得分、等级、评语和最近检测时间。
- 下方只保留按优先级排列的 GEO 建议。
- AI 可见性监测从主导航移除，能力合并到诊断页。

### 关键词

- 页面标题由“关键词与内容计划”改为“关键词”。
- 一条长尾问题一行，展示主关键词、长尾关键词、类型、用户意图、优先级和文章数。
- 支持搜索、筛选、单选、多选、全选、编辑、删除、重新生成及批量生成内容。
- 重新生成保留人工编辑、已选择或已有文章的关键词。

### 内容工作台

- 列表展示标题、关键词、类型、状态和更新时间。
- 支持批量生成数量、文章长度和写作风格设置。
- 支持查看、编辑、复制、发布标记和可恢复删除。
- 页面不再展示生成依据、导出、复杂版本区和渠道版本区。
- 后台继续保留事实快照、质量检查和历史版本，避免降低事实安全性。

## 兼容与迁移

- 现有诊断、策略、简报、文章、版本和质量记录不删除。
- 关键词新增结构化字段，旧数据通过可逆迁移回填。
- 删除关键词和文章采用软删除/归档。
- 保留原监测 API 和页面路由，先从导航隐藏，便于回滚。

## 原型豁免

产品负责人已经确认页面职责、字段和操作，且沿用现有明亮蓝色设计系统。本次直接在
真实页面中完成设计，不另做独立宣传式原型。

## 验收标准

1. GEO 诊断不再展示五维分数和 L0—L4 阶梯，改为平台表现、100 分评分、等级、
   评语和 GEO 建议。
2. 未检测、检测失败和未发现严格区分，只有有效样本参与评分。
3. 关键词以列表展示主关键词、长尾关键词、类型、用户意图、优先级和选中状态。
4. 关键词支持多选、编辑、软删除和进入批量内容生成。
5. 内容工作台支持批量生成配置、文章列表、查看、编辑、复制、发布标记和软删除。
6. 文章仍通过事实快照和质量检查约束，不虚构企业信息，不承诺平台收录或推荐。
7. 受影响后端、前端测试、类型检查和构建通过，独立 Tester 给出结论。
