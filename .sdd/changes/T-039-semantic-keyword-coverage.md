# T-039 关键词语义覆盖

## 问题

文章已经自然表达“在即墨区给孩子选美术班”，但目标关键词为
“即墨区少儿美术培训机构”时，旧规则仍要求核心字符串连续出现，导致语义一致的
文章被提示“正文没有自然覆盖目标关键词”。这会反向诱导模型机械插入关键词，
降低文章多样性和真人表达感。

## 变更目标

- 关键词质量检查从“完整字符串匹配”升级为“语义要素覆盖”。
- 地区、服务对象、核心业务和搜索意图允许采用自然同义表达。
- 企业类型词和搜索问句后缀不要求逐字复现。
- 核心业务缺失或文章明显跑题时仍然提示。
- 写作提示词明确允许同义表达，不要求逐字复现关键词。

## 接受标准

1. “即墨区少儿美术培训机构”与“在即墨区给孩子选美术班”可判定为语义覆盖。
2. 只出现地区、孩子和“兴趣班”，但缺失“美术”时仍然提示。
3. 品牌关键词和精确业务限定词不能因过度宽松而被忽略。
4. 现有关键词重复检查继续工作，避免关键词堆砌。
5. 最新真实文章重新检查后不再产生该项误报。
