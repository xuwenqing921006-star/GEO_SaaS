# T-066 文章发布独立工作区变更说明

- 状态：Approved
- 日期：2026-08-09
- 产品负责人确认：用户已明确要求删除内容统计和工作台文章列表，并在内容工作台下新增文章发布。

## 目标

将“生成文章”和“管理/发布文章”拆成两个清晰入口：内容工作台只负责生成配置与生成任务；文章发布集中承载文章筛选、查看、编辑、复制、删除、恢复和选择发布。

## 页面与流程

1. 左侧导航在“内容工作台”下新增“文章发布”。
2. 内容工作台保留生成配置、开始 AI 生成和生成任务列表。
3. 内容工作台删除文章总数/生成中/可发布/已发布四张统计卡片。
4. 内容工作台删除完整文章列表。
5. 文章发布页面展示原文章列表及全部筛选、状态、编辑和发布操作。
6. 从生成任务详情仍可查看或编辑本次生成文章。

## 兼容与非范围

- 不删除文章、版本、发布记录或归档数据。
- 不修改后端接口、数据库结构、发布规则或账号配置。
- `/content` 保持为内容工作台；新增 `/publishing` 作为文章发布页面。
- 原有文章详情和发布弹窗复用，不复制一套业务逻辑。

## 验收标准

- 内容工作台不存在内容统计卡片和完整文章列表。
- 左侧“文章发布”紧随“内容工作台”，选中态和客户参数正确。
- 文章发布页面显示文章列表、筛选、当前/已删除切换及全部文章操作。
- 内容工作台生成任务详情仍能查看和编辑文章。
- 两个页面的空白、加载、错误和弹窗状态可用，无控制台错误。

## 测试策略

- 先增加文章发布路由失败用例。
- 执行前端定向单测、全量类型检查、Lint、格式检查和生产构建。
- 使用本地真实浏览器分别核对 `/content` 与 `/publishing`。
- 独立 Tester 最终判定任务状态；Developer 不自行标记通过。
