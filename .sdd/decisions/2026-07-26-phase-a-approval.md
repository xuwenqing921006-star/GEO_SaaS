## 已确认范围

- A1：单负责人产品的页面清单、全局导航和客户级主流程。
- A2：9 个页面（含安全登录入口）、71 项功能及其明确边界。
- A3：V1/MVP、V1.1、V2+ 划分和五个交付里程碑。
- A4：企业事实、GEO 诊断、双模型内容、自然化、渠道推荐和多平台监测反馈链路。
- A5：业务数据、统一接口响应、外部依赖和缺失时降级策略。

## 外部依赖确认

- 产品负责人提供 DeepSeek 和阿里云百炼 API Key；模型 ID 可配置，开发前使用莱恩美术测试集确定主写与检查的默认分工。
- V1 使用本地文档解析/OCR、PostgreSQL 和本地受保护文件目录；不购买云 OCR。
- DeepSeek、通义千问使用官方 API 监测；豆包、元宝、Kimi、百度等消费者平台首版人工粘贴真实回答。
- 系统不保存消费者 AI 平台账号密码，不做模拟登录和受保护页面自动化。
- 本次确认不授权充值、购买云资源、生产部署或其他付费开通。
