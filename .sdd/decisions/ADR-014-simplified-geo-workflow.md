# ADR-014：在现有数据模型上兼容式简化 GEO 工作流

## 状态

Accepted，2026-07-28。

## 决策

- 复用现有监测样本和评估记录计算平台评分，不创建一套重复的“收录”数据。
- 在诊断 `scores` JSON 中保存本次平台评分快照，并通过响应契约输出结构化结果。
- 为关键词补充主关键词、用户意图和选中状态字段，继续复用策略项及内容简报。
- 批量内容生成按所选关键词动态创建简报、文章和既有生成任务。
- 删除采用 `active=false` 或 `status=archived`，发布采用 `status=published`。
- 原 AI 可见性监测路由保留但从导航隐藏。

## 原因

这能最快形成用户确认的新闭环，同时保留历史内容、事实追溯、质量检查、预算控制和
监测能力，避免高风险重建。

## 回滚

- 回滚前端即可恢复旧页面入口。
- 新增关键词字段为可空/有默认值，不影响旧记录。
- 诊断 JSON 新字段可被旧版本忽略。
- 归档数据可恢复，发布状态可改回可发布状态。
