# ADR-018 用可观察来源信号替代“平台权重”断言

## 状态

已接受，2026-08-04。

## 背景

用户需要从四个平台回答的关联文章或参考资料，判断竞品为何出现，并了解哪些内容发布渠道
对 AI 回答影响更大。平台真实排序权重未公开，且 API 与消费者 App 不完全等价。

## 决策

系统只保存和计算可观察证据：回答文本、品牌出现顺序、推荐语、搜索来源标题、URL、域名、
对应问题和检测平台。渠道层展示“来源影响信号”，不展示“官方权重”。

信号由以下维度组成：

1. 跨平台覆盖；
2. 检测问题覆盖；
3. 来源出现次数；
4. 来源标题对竞品的直接支撑。

所有分值同时展示样本量和置信度。没有来源能力的平台不进入来源分母，也不会被计为 0。

## 后果

- 优点：结论可复核、可解释，不伪造平台算法。
- 缺点：初期样本少时只能得到低置信度方向；API 观察无法替代消费者端验收。
- 后续：积累跨时间诊断后，可在相同口径下增加 30/90 天趋势，但仍保持“观察信号”命名。
