# T-042 头条号真实编辑器适配

## 问题

首个真实发布任务失败并提示“头条号发布按钮不可用”。任务数据和登录状态均正常，
实际原因是自动发布适配器没有跟上头条号当前编辑页：

- 平台按钮名称是“预览并发布”，旧代码只识别“发布/确认发布”。
- ProseMirror 正文编辑器不会持久接受 `fill()`，页面重新渲染后正文恢复为空。
- 头条创作助手抽屉会遮挡封面交互。
- 封面必须先选择“单图”、打开上传面板、使用本地上传输入并确认。

## 修复

- 关闭创作助手遮罩后再填写文章。
- 标题按头条号当前 2～30 字限制填写。
- 正文通过真实键盘事件按段输入，并在发布前确认编辑器已识别正文。
- 选择单图封面，完成上传并确认封面状态。
- 作品声明默认选择“个人观点，仅供参考”，并取消可能沿用的“引用AI”。
- 适配“预览并发布”→“确认发布”两段流程。
- 缺标题、缺正文、封面失败或页面流程变化时返回具体错误。
