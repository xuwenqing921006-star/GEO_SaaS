# T-059 综合验收缺陷修复记录

## 环境与影响

- 环境：Windows 本地开发环境，FastAPI + PostgreSQL + Vue 3。
- 来源：T-058 全量功能、按钮、流程、UI 与真实付费模型综合验收。
- 影响：文章可能携带知识库未支持的收费事实；长任务反馈不可信；诊断存在重复失败请求；自动化基线无法作为发布门槛。

## 已复现问题

1. **P1 文章事实校验假阴性**
   - 预期：明确要求删除“免费、不收费、材料费”等无依据表述后，重写结果不再包含这些说法；如仍包含，质检必须阻断。
   - 实际：第三版仍包含“体验课通常不收费”，复检却提示没有明确发布风险。
2. **P2 长任务进度恒为 0%**
   - 预期：任务展示真实阶段或逐步进度。
   - 实际：诊断、关键词和文章重写在完成前始终显示 0%。
3. **P2 供应商能力重复探测**
   - 预期：使用已验证端点；不支持的来源检索能力只判定一次。
   - 实际：千问每题先返回 400、豆包每题先返回 404，再降级到成功端点。
4. **P2 关键词自然度异常**
   - 预期：用户问题简短口语化，并围绕单一意图。
   - 实际：存在多个症状和场景堆叠的长问题。
5. **P1 自动化发布门槛失效**
   - 预期：当前产品关键 E2E 全绿。
   - 实际：15 项中 10 项使用旧页面、按钮和平台结构而失败。
6. **P1/P3 工程检查未全绿**
   - OpenAPI 实际和文档均为 82，但测试硬编码 81。
   - `frontend/src/api/dto.ts` 未通过 Prettier。
   - 5 项 PostgreSQL 并发或容量测试因缺少隔离测试库而跳过。
   - Bandit 有 4 个低风险项待澄清或收敛。
7. **P2/P3 UI 与语义问题**
   - 部分次要文字对比度约 2.63:1 至 3.34:1。
   - 数据表缺少可访问名称或 caption。

## 修复原则

- 先添加能稳定复现的失败测试，再修复实现。
- 不降低现有断言强度，不以跳过测试换取全绿。
- 不记录、输出或改写任何真实 API 密钥。
- PostgreSQL 验证必须使用独立测试数据库。
- 真实发布不属于本任务授权范围。

## 修复结果（2026-08-05）

1. **文章事实校验假阴性：已修复**
   - 对“免费、免收费、不收费、材料费”等收费政策建立知识库支持检查。
   - 问句中的费用词不会被误判为企业承诺；正文中的无依据陈述会阻断发布。
   - 历史文章重新检查后已识别“体验课通常不收费”，页面显示 1 项发布风险和修改建议。
2. **长任务进度恒为 0%：已修复**
   - Worker 按真实执行阶段写入步骤和 1—99% 的有效进度。
   - GEO 诊断、关键词、文章生成、质检和重写均保留完成、失败、超时通知。
3. **供应商能力重复探测：已修复**
   - 千问使用兼容 Chat Completions 与联网检索参数。
   - 豆包首次确认 `/responses` 不可用后缓存路由结果，后续问题直接使用 `/chat/completions`。
4. **关键词自然度异常：已修复**
   - 增加短查询、单一意图、禁止直接搬运课程/人群清单的提示和结果规范化。
   - 过长、堆叠意图的旧 AI 关键词会被停用，重新生成结果使用自然短问法。
5. **自动化发布门槛失效：已修复**
   - 旧 Mock E2E 已与当前真实页面、按钮、三平台诊断和多渠道结构同步。
   - Playwright 当前 11/11 通过。
6. **工程检查：已修复**
   - OpenAPI 数量断言、DTO 格式、Bandit 低风险项均完成处理。
   - 前端完整检查、后端静态检查、安全检查和依赖审计均通过。
   - 5 项 PostgreSQL 并发/容量用例使用 `geo_saas_t059_test` 隔离库补跑通过。
7. **UI 与语义：已修复**
   - 提升辅助文字对比度，为数据表补充可访问名称。
   - 修复 1024—1359px 下客户、关键词、文章操作列被裁切的问题。
   - 禁用按钮统一使用 `not-allowed` 光标；左侧导航长页面保持固定。
8. **诊断结果语义：已修复**
   - 只有品牌直查命中时显示“仅品牌词可见”，不再计入品类发现或推荐得分。
   - 优化建议按实际问题覆盖数、内容形式和实际参与检测的平台数量生成，不再出现 5/5 已覆盖却提示覆盖不足、三平台写成四平台等矛盾。
