# T-034 停止内容工作台空闲轮询

## 问题

内容工作台的文章列表固定每 2 秒重新请求一次，即使没有任何文章处于等待生成或生成中状态。多个浏览器标签页会叠加请求，造成无意义的接口和数据库负载。

## 修复

- 只有存在 `brief` 或 `generating` 状态的文章时，每 2 秒刷新文章列表。
- 所有文章进入完成、失败、待修正、已发布或已归档等终态后停止轮询。
- 创建、编辑、重新生成、质检、发布和删除后的显式刷新保持不变。

## 验证

- 轮询条件单元测试覆盖无数据、终态、等待生成和生成中状态。
- 当前客户只有一篇 `blocked` 文章，连续 6 秒 API 日志观察新增文章列表请求为 0。
