# T-033 关键词到首轮 AI 监测断链修复

## 问题

关键词页面已在简化改版中隐藏旧版“问题项”，但 AI 可见性监测仍要求运营人员锁定旧版问题集。页面没有可完成该操作的入口，导致首轮监测无法建立。

## 调整

- 关键词页面的“已选择”状态同时作为监测问题确认状态。
- 监测页在没有冻结问题集时，从已选关键词自动建立冻结问题集。
- 首轮最多抽取 5 个不同用户意图的代表问题，优先覆盖地区发现、推荐决策、品牌核验、场景适配和选择比较。
- 首轮 DeepSeek、通义千问每题采样 1 次；后续监测批次仍使用 3 次采样。
- 监测页在按钮前明确显示准备状态、问题数量和前往关键词页的入口。
- 冻结问题集创建后锁定所引用关键词，确保后续批次仍可复用。

## 边界

- 不自动选中关键词，仍由运营人员决定监测问题。
- 不在进入页面时自动调用付费模型。
- 其他消费者端平台仍只创建人工采样占位，不伪装为 API 自动监测。
- 历史冻结问题集继续兼容。
