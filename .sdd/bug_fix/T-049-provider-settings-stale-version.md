# T-049 模型配置保存返回 40901

## 期望行为

- 连接测试失败后，用户可以修正配置并再次保存或验证。
- 页面持有的模型配置版本应与服务端同步。
- 同一个模型的保存和测试不能并发提交。

## 实际行为

- 连接测试失败会更新服务端配置版本，但页面没有重新读取该版本。
- 下一次保存继续提交旧版本，返回“模型配置已被更新，请刷新后重试”。
- 测试进行中仍可点击“保存配置”，存在并发写入窗口。

## 根因

模型测试接口会记录成功或失败状态，并以原子更新方式递增配置版本。前端只在测试
成功后重新加载设置，失败路径保留了旧版本；保存按钮也没有受测试状态约束。

## 修复范围

- 测试请求已经进入服务端后，无论成功或失败均重新同步设置。
- 保存遇到 409 冲突时自动重新加载当前版本，同时保留错误提示。
- 测试进行中禁用同一模型的保存按钮。
- 增加版本冲突与测试失败回归用例。

## 开发验证

- 新增前端回归：409 保存冲突后自动加载最新版本，下一次提交使用新版本。
- 新增前端回归：连接测试失败后自动加载测试写入的新版本，测试期间保存按钮禁用。
- 前端 Vitest：11 个测试文件、66 个测试全部通过。
- ESLint、Vue TypeScript 类型检查和 Vite 生产构建通过。
