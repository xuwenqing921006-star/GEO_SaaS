# T-032 真实模型驱动的文章生成质量修正

## 问题

- 文章“AI 按建议重新生成”仍把旧正文完整交给模型，模型容易只做局部替换，
  继续保留旧稿的机械结构、高风险宣传话术和过时数字。
- 企业知识库中同时存在 `4-16岁` 与 `4-18岁` 两种服务口径，生成模型与审核模型
  使用的事实边界不一致，导致文章反复被判为年龄范围冲突。
- 原始企业介绍中的“最专业、率先、最佳学习效果、运营年限、服务人数”等营销性
  语句被直接作为写作事实，放大了内容违规和事实过时风险。
- 审核上下文携带内部事实与证据 ID，独立模型可能把上下文中的 ID 误认为正文泄漏。
- 规则检查把“选择一家”中的“一家”误认为企业数量主张，并要求目标关键词必须
  完全连续出现，不能识别“在即墨区寻找少儿美术培训机构”等自然表达。

## 目标行为

- AI 重新生成必须基于企业安全事实、目标关键词、内容形式、渠道规则、人工修改建议
  和上一版质量问题从零重写，不再向模型提供旧正文。
- 写作与审核使用同一套安全事实：过滤高风险营销分句，对冲突属性采用更窄、更保守
  的范围，并保留其他服务的独立说明。
- 审核上下文不包含 UUID、事实 ID、证据 ID或原始证据引用文本。
- “选择一家、推荐一家”等指代性表达不作为企业规模事实；“设有一家门店”等明确
  数量陈述仍需知识库支持。
- 关键词在首段自然完整出现一次；检查规则可识别少量连接词造成的自然语序变化，
  同时继续限制关键词堆砌。

## 实施结果

- 新增安全事实清洗、冲突年龄范围收敛及统一审核上下文。
- 重新生成提示只提供上一版本标题与质量问题，不提供旧正文，并明确要求从零重写。
- 成立年份结构化事实可支持“成立于2017年”等自然表达。
- 数量检查忽略“选择一家”等普通指代表达，保留“设有一家”等真实规模检查。
- 关键词检查可识别“即墨区寻找少儿美术培训机构”等自然覆盖方式。
- 常规批量写作仍由千问负责；按人工建议严格重写改由 DeepSeek 主写、千问备用。
- 每次人工修改建议作为“人工修改”规则快照保存在文章版本中，之后单独重新质检仍
  使用同一要求，不会因为任务结束而丢失。
- 审核前把人工建议拆成硬约束清单，过滤结论为“符合要求、无需修改、不应报告”的
  无效问题。
- 严格重写内部合并规则检查与独立模型检查；候选未通过时最多自动从零修复两次，
  两次后仍有问题则保持待修正，避免无限调用。
- 真实代表文章最终生成到第 11 版，由 DeepSeek 严格重写；生成后检查和隔离重新
  质检均为 0 项问题，最终状态为“质量通过”。

## 实施边界

- 本任务只修正内容生成与质检事实边界，不自动修改客户知识库原始资料。
- 真实模型调用由用户明确授权，仅验证一篇代表文章及必要质检，不批量重写其他文章。
- 单次严格重写最多产生 3 次写作和 3 次复核调用；候选提前通过时立即停止后续调用。
- 任务保持 `in_progress`；Developer 自验不替代独立 Tester 验证和 Product Manager
  业务验收。
