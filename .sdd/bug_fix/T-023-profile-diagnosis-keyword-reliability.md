# T-023 客户资料、诊断说明与关键词生成可靠性修复

## 期望行为

- 客户资料完整度根据当前企业基本信息与知识库基础资料实时计算。
- 没有真实 AI 问答样本时，诊断明确说明“尚未检测”，不能让用户误解为
  “已经检测但没有收录”。
- 千问或 DeepSeek 返回可理解的 JSON 变体时，关键词任务能够正常解析并生成。

## 实际行为与影响

- `clients.fact_completeness` 创建后从未更新，即使已有 21 条知识仍显示 0%。
- 当前客户没有监测批次和问答样本，页面虽显示未检测，但没有在首屏解释诊断
  不会自动登录平台搜索。
- 模型请求 HTTP 200，但关键词结构校验要求固定字段、固定外层对象、至少 12 条且
  禁止额外字段，常见模型 JSON 变体被整体判为格式异常。

## 根因

1. 客户 API 直接返回遗留持久化字段，没有从基础资料重新计算。
2. 平台评分严格依赖成功且已评估的监测样本，当前客户数据库中监测批次、样本与
   评估均为 0；页面说明不够显眼。
3. 模型结构 Schema 过度严格，解析器也不接受 Markdown JSON 代码块、前后说明、
   `keywords` 外层字段、字段别名、中文类别和额外解释字段。

## 修复范围

- 按企业名称、行业、地区、主营服务、企业介绍、目标客户、企业优势和联系方式
  八组基础资料动态计算 0—100% 完整度。
- 无有效样本时增加首屏解释与“建立真实检测样本”入口，并把按钮改为
  “重新计算诊断”。
- 增强通用 JSON 提取和关键词模型字段归一化，保留事实与六类关键词校验。
- 分别校验主关键词和长尾关键词必须与企业品牌、服务地区或主营业务相关，并在
  AI 漏掉类别时自动补齐地区主营、企业品牌、推荐决策、场景适配、服务细分和
  对比选择六类关键词。
- 关键词重新生成只有在新结果成功产出后才替换当前列表；模型限流或服务异常时，
  保留上一版有效策略及其诊断版本，不会出现旧内容被清空、版本却已前进的情况。
- 仅把公开电话、微信等联系方式计入资料完整度，营业时间等其他联系类字段不能
  冒充联系方式。
- 取消修复前遗留的运行中关键词任务，避免重复调用模型。

## 接受标准

1. 当前青岛莱恩美术教育客户的 21 条知识可计算为 100%，列表与顶部摘要一致。
2. 新建但未录入知识库的客户不会错误显示 0%，而是按已有基本信息显示 35%。
3. 没有监测样本时清楚说明这不代表未被收录，平台评分仍显示“—”而不是 0。
4. 关键词解析兼容 JSON 代码块、外层 `keywords`、常见字段别名、中文分类、
   优先级文字和额外字段。
5. AI 返回偏题关键词时不入库，最终列表至少覆盖六类搜索意图。
6. 模型非格式类失败时保留上一版诊断关联与有效关键词。
7. 受影响后端、前端检查与真实页面回归通过。
