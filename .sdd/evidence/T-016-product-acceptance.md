# T-016 Product Manager 业务验收

- 验收时间：2026-07-28（Asia/Shanghai）
- 验收角色：Product Manager
- 验收对象：全站明亮视觉与弹窗体验重构最终版本
- 验收方式：独立代码复核、Reviewer/Tester 证据交叉检查、本地真实 Web 只读视觉与交互抽查
- 最终结论：**ACCEPT**
- 业务阻断：**0 项**
- 用户最终视觉确认门禁：**保持开放**
- 生产部署：**未执行**

## 1. 验收口径

本次验收只判断 T-016 是否把既有 GEO SaaS 业务闭环升级为适合单人代运营的明亮 Web 工作台，同时保持 T-014 已接受的业务流程和结果边界不变。

验收重点：

1. 全站是否具有一致且可连续工作的明亮工作台体验。
2. 蓝色是否明确表达品牌、导航和操作，绿色是否只表达业务结果。
3. 弹窗首屏、内容层级、滚动和固定操作区是否支持真实操作。
4. 视觉重构是否改变客户、知识库、诊断、策略、内容、渠道、监测和设置流程。
5. “提高被理解、检索、引用和推荐的机会，但不承诺结果”的业务边界是否保留。

技术测试 PASS 是本次业务验收的输入，但不直接替代 Product Manager 的产品判断。

## 3. 独立 Web 抽查记录

### 3.1 客户工作台

真实 Web 抽查确认：

- 左侧 8 个工作区图标和中文名称完整；
- 当前“客户工作台”为浅蓝选中态；
- “新建客户”为蓝色主按钮；
- 客户表格使用绿色表达活跃、L 级等业务状态；
- 右侧“下一步”把待补条件和下一步行动集中呈现；
- 顶栏持续展示当前客户、资料完整度、L 级、阻断和下一步。

从单人代运营角度，首屏已经能够回答“当前在服务谁、现状如何、最先做什么、从哪里继续”，适合日常连续处理多个客户。

### 3.2 普通长表单弹窗

打开“新建客户”后，Product Manager 实际确认：

- 标题、说明、字段、滚动区和底部操作区层级清楚；
- 页面背景被弱化，当前任务焦点明确；
- 表单内容超过可用高度时内部滚动；
- “取消/创建客户”固定在底部可见区域；
- Escape 关闭后弹窗数量从 1 变为 0，页面滚动状态从 `hidden` 正常恢复。

### 3.3 证据与授权弹窗

使用真实维修服务客户资料打开“证据与授权”，首屏可见：

- 事实类型“服务项目”；
- 事实内容“提供家电与水电维修服务”；
- 当前状态“客户提供”；
- “修改事实”“标记为仅内部”操作；
- 证据记录及文件/片段来源；
- 公开授权状态和后续补证入口。

该弹窗已经围绕“这是什么事实、现在能否使用、依据在哪里、下一步做什么”组织信息，适合单人运营快速判断。

### 3.4 大型知识档案弹窗

本地真实 Web 实测：

- 弹窗使用 `modal--large`；
- 正文可视高度约 506，内容滚动高度约 1245；
- 操作区底部约 611，未超过弹窗底部约 612；
- 长内容滚动时仍可直接执行取消或保存。

因此旧版长表单操作按钮被内容推到屏幕外的问题已关闭。

### 3.5 内容工作台

内容页保持单一主任务“AI 生成新文章”，并把文章列表、正文区、生成依据、企业事实快照、内容简报、质量门禁和渠道适配作为清楚的次级层。蓝色主按钮负责执行，绿色继续表达事实/结果状态，符合单人代运营的操作语义。

4. 亲自查看证据弹窗、新建客户长表单和大型知识档案弹窗，确认尺寸、间距和滚动手感。

用户最终视觉门禁保持开放，不应因本报告自动关闭。
