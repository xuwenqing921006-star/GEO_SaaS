# T-011 任务记忆

- 渠道推荐必须按客户、行业、地区、诊断缺口和每篇内容简报计算，不能把静态渠道目录冒充个性化建议。
- 行业代码必须使用客户模块的规范值；少儿美术为 `art_education`，迁移时需处理旧别名。
- 每篇内容应同时保留运营方、客户配合和合作渠道，当前基线为 4+2+1；前端不能只截取前四条。
- 渠道建议的执行字段至少包括：改编、账号定位、授权、费用、风险、目标生态、动作、官方入口和不保证声明。
- 历史推荐必须冻结渠道目录与内容简报快照；读取旧记录不能回查当前可变目录。
- 新代次生成应在单事务内失活旧代次并写入新代次；同客户任务使用行锁串行化，失败必须整体回滚。
- 幂等键应规范化 brief IDs 和 ownership；并发冲突后重查 winner，相同参数复用 202，不同参数返回 409。
- 渠道目录只提供人工执行建议，不保存第三方登录凭据，不创建自动发布、定时发布或链接回填接口。
- 官方入口和规则需要版本化维护；实际收录、引用和推荐必须由后续监测验证。
- 独立结论：Reviewer PASS、Tester PASS、Product Manager ACCEPT。
