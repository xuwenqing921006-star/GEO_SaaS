# T-070 经验记录

- 来源：头条号账号因批量低质内容被禁言后的规则收口。
- 范围：文章生成合同、确定性质量门禁、头条号发布节流。
- 日期：2026-08-10。
- 置信度：高。

## 经验

- 平台规则不能只写入提示词，还要转换为可重复执行的确定性门禁，否则模型仍可能输出软文、转化表达或同质结构。
- “企业名称次数”与“企业相关句子占比”需要同时控制；只限制名称次数会留下“该机构、其课程”等隐性品牌曝光。
- 平台未公开固定安全发布量时，应清楚标注内部节流属于账号保护策略，不将经验阈值包装成官方规则。
- 固定模拟测试必须绕过真实账号节流，避免工程回归测试因运营保护策略产生不稳定失败。
