# T-073 交接整理记录

- 日期：2026-10-13。
- 来源：产品负责人要求普通独立工程交接；当前源码、任务记录和聚焦审查证据。
- 范围：geo-saas 文档、工具入口、开发环境示例与本地 Git；不涉及业务功能、生产部署或数据迁移。
- 置信度：高（入口、文件哈希、任务覆盖和配置解析已核验）；新电脑完整启动与真实平台发布仍待实际验证。

## 经验

- 业务工程可以独立运行；开发流程工具只应作为团队选择，移交源码不应把原作者工具版本或绝对路径当作运行依赖。
- 移除工具绑定需要同时核对 AGENTS、CLAUDE、IDE 自动规则与自动加载的本机配置，不能只改 README。
- 历史进行中任务可能已有开发实现，交接应保留原始状态、验收条件、报告与后续修复关系；开发报告不等于当前完整验收。
- Vite 配置如果只读取 process.env，`.env.local` 的代理变量不能直接生效；交接应记录实际读取方式，避免为修正文档而修改业务配置。
- 现有源码不受父级 Git 跟踪时，需要单独建立本地仓库和敏感/生成文件忽略规则；原始差异与业务 SHA-256 用于确认整理没有混入业务变更。

后续开发者无需沿用本记录使用的 ECC 过渡流程；这是历史交接证据，不是团队新流程的强制要求。
