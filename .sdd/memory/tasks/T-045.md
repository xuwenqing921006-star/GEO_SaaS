文章版本当前只支持一个 `target_channel_id`，因此多渠道批量生成不能把多个渠道塞进同一
版本。正确做法是按目标渠道展开任务，为每个渠道保存独立提示词、联系方式策略和发布
目标；这样后续一键发布仍能明确路由。

封面应优先复用文章已经绑定且归属当前客户的企业图片。该方式比固定 GEO 模板更贴近
文章内容，也不会虚构客户现场；缺少企业图片时才回退到纯图形标题封面。

图片删除不仅要移除文件和资料记录，还必须遍历同客户文章版本并清除 JSON 图片 ID，
避免详情与发布阶段出现失效图片引用。
