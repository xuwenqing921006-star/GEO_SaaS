# T-043 Memory

- source: T-043 implementation and local verification
- scope: project
- confidence: high
- date: 2026-07-30

企业图片应作为独立资料类型复用现有安全存储，不进入 OCR 和事实提取。文章版本保存
图片资料 ID，比在正文中保存本地路径或临时 URL 更稳定，也能在发布时重新校验客户
归属、授权状态和文件存在性。

浏览器自动发布的正文图片应先完成正文输入，再按段落比例定位光标、上传图片并确认
插入节点，最后独立处理封面。图片选择在文章生成时固化；旧文章只在首次发布时补选，
避免每次重试改变配图。
