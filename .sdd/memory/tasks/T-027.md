# T-027 任务记忆

- 提示词快照必须既可追溯，也必须实际进入模型；保存五层记录但只渲染四层不算完成。
- 内容形式的必需事实要在快照上限前按分组保底，避免大量同类资料挤掉价格或流程依据。
- 渠道联系方式清理需覆盖半角、全角、点分、空格、二维码 Markdown/HTML 和站外链接。
- 可编辑渠道模板必须位于只读保护层内部，并以不可覆盖声明结束。
- 跨文章重复检查必须覆盖生成、编辑、恢复、优化、渠道适配和发布；被淘汰草稿不能反向阻断保留文章。
- 已应用迁移仍需使用新的向前迁移修正规则数据；离线 SQL 也不能生成空参数。
- 文章不自动发布，且不得承诺任何 AI 平台一定收录、引用或推荐。
- 独立结论：Reviewer PASS、Tester PASS、Product Manager PASS。
