# T-010 任务记忆

- 内容生成必须冻结客户、简报、事实和证据上下文；后续版本始终引用同一事实快照。
- 主写与独立复核必须使用不同角色；复核不可用时故障关闭，不能用“请求失败”冒充“未发现问题”。
- 人工编辑、优化、自然化、渠道改写和恢复均追加不可变版本，不能覆盖历史。
- 中文自然化必须保护事实值出现次数；渠道适配必须改变标题、导语、结构或篇幅，不能只增加渠道标签。
- 未保存正文时必须保护编辑状态，禁止切文章、优化、渠道改写、恢复和导出。
- 模型用量提交不能提交内容事务：PostgreSQL 使用独立用量会话，SQLite 测试使用 `commit=False`。
- 多渠道任务必须整体原子；任一渠道失败不得留下部分版本，重试不得生成重复渠道版本。
- 文档行锁必须贯穿版本校验、模型复核和写入；相同版本并发保存只能一个成功，另一个返回 409。
- 导出必须包含标题、事实、来源 URL / 日期 / 摘录和发布验证建议，并明确不承诺收录或推荐。
- 独立结论：Reviewer PASS、Tester PASS、Product Manager ACCEPT。
