# T-068 经验记录

- 来源：文章确认发布队列综合验收缺陷修复。
- 范围：geo-saas 内容生成、发布预检、E2E 与依赖安全门禁。
- 日期：2026-08-10。
- 置信度：高。

## 经验

- 平台图片、账号和规则约束必须在用户提交生成请求时同步校验；只在 Worker 中校验会制造必然失败或部分失败的任务，增加运营人员排查成本。
- 页面流程重构完成后，要同步更新真实 E2E 的业务语义，而不只是替换按钮文本；关键词候选确认和文章任务确认都是发布闭环的关键门禁。
- 外部发布 E2E 必须使用固定模拟执行模式，避免自动测试意外启动持久浏览器、使用渠道会话或产生真实内容。
- 依赖审计不仅要检查直接依赖，也要约束存在漏洞的传递依赖版本，并在锁文件中验证最终解析结果。
