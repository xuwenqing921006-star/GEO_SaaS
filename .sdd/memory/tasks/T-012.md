# T-012 任务记忆

- 国内主流 AI 监测必须显式区分 API 自动采样与消费者端人工采样；二者不能共享指标分母。
- `failed`、`not_executed`、成功但未提及是三种不同业务状态，失败与未执行不能计入有效回答分母。
- 监测批次只允许使用当前客户 P04 已确认、激活且锁定的问题；批次创建时必须再次验证，不能只相信历史 `frozen=true`。
- 品牌核验问题用于验证实体关联，不进入无品牌发现率和推荐率。
- 自动分析可以判断是否提及、关联、推荐和可见来源，但事实准确与推荐理由有据必须保持待人工核验。
- 重复出现率按同一问题 ID、P1 优先级和至少两次成功样本分组，不能把不同问题或不同采集方式合并。
- 指标 API 必须返回每项分子、分母、比率和时间范围；未执行占位样本按创建时间进入窗口。
- P07 必须真实使用时间范围指标接口，展示发现、关联、推荐、事实准确和重复出现五项及 `n/N`，接口失败时不能用最新批次冒充。
- 监测异常必须转换为持久化、唯一且可查询的改进任务；Web 需要显示任务详情和 P02/P04/P06/P07 执行入口。
- 同一客户的批次创建、问题集修改和 Worker 领取使用数据库锁与租约；旧 attempt 或过期 lease 不能提交结果或重复产生付费调用。
- 迁移降级必须先处理新增 nullable 数据，再恢复旧非空约束；结构默认值需与父版本精确一致。
- 独立结论：Reviewer PASS、Tester PASS、Product Manager ACCEPT。
