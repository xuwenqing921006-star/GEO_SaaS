# T-066 经验记录

- 来源：内容工作台与文章发布工作区拆分。
- 范围：geo-saas Web 导航与内容模块。
- 日期：2026-08-09。
- 置信度：高。

## 经验

- 文章生成与文章发布属于两个不同阶段。将两者拆开后，内容工作台更聚焦任务创建，文章发布更适合承载筛选、状态和账号操作。
- 迁移页面入口时优先复用同一业务组件的模式边界，能够避免复制文章编辑、质量修正和发布逻辑；后续组件继续增长时再拆为共享 composable 和两个专用列表组件。
- 新导航必须保留 `clientId`，并同步客户工作台的下一步任务路由，否则容易切换到错误客户上下文。
- 页面拆分验收需要同时检查旧页面不存在原模块、新页面完整承接能力，而不能只验证新增路由能打开。
