# T-028 经验记录

## 现象

GEO 诊断任务在读取 AI 监测样本时失败，页面只显示通用任务异常。

## 根因

数据库迁移角色创建了新业务表，但持久化数据卷中的运行角色权限没有在迁移后重新同步，
导致代码与数据库对象都正确，实际运行环境仍无法查询新增表。

## 处理原则

- 优先使用项目已有的幂等角色同步脚本，不做临时单表手工授权。
- 同时检查所有业务表权限完备性，避免只修复首个报错表。
- 权限补齐必须维持最小权限：业务 DML 与序列使用，不授予 DDL 或管理员能力。
- 诊断恢复后应验证用户可见语义：无样本是“未检测”，不是失败，也不是 0 分。

## 后续建议

数据库迁移完成后自动执行角色权限同步，并把“所有 public 业务表均可由运行角色读取”
纳入部署健康检查或发布门禁。
