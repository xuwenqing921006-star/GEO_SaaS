# T-029 经验记录

## 关键经验

- “已发布”是已经发生的外部事实，不能只作为会被质量检查覆盖的工作流状态；应独立记录
  发布版本、渠道和时间。
- 组合筛选若只读取第一页，会在数据增长后静默漏项；小规模单人系统可先完整拉取分页，
  未来数据量增大再升级为服务端筛选。
- 页面禁用条件必须在后端重复执行关键业务校验，尤其是诊断或企业事实快照过期。
- 渠道联系方式清理不能只覆盖带冒号的固定标签，应识别“动作 + 联系媒介 + 标识”的常见
  变体，同时保护“不要、谨防、禁止”等否定警示语。
- 提示词版本是历史文章的生成依据；迁移回滚必须追加新版本，不能删除已被文章引用的历史。

## 内容平台结论

- 通用 GEO 稿不等于渠道合规稿。
- 搜狐号对地域搜索式标题、常用疑问式标题、营销软文、联系方式、重复堆词和相似内容尤其
  敏感。
- 百家号和头条号同样需要保守处理联系方式、站外导流、夸张标题和营销招揽。
- 平台公开规则会变化，系统只能降低风险，发布前仍需人工复核。

## 验证原则

- 合规清理必须同时测试标准写法、无分隔符写法、动作式导流和否定语保护。
- Reviewer、Tester 和 Product Manager 都通过后，任务才能标记为 passed。
