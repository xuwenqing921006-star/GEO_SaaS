# GEO SaaS V0.1.0 候选版发布说明

发布日期：2026-07-28  
状态：可部署候选版，尚未生产上线

## 交付结果

- 面向单一平台运营负责人的 Web 工作台，客户无需登录。
- 支持通用本地服务企业建档、资料解析、事实确认和证据追溯。
- 根据企业资料、地区、行业、关键词与问题意图生成 GEO 内容计划和文章。
- 文章由 AI 首稿生成，运营人员在生成后查看、编辑、保存版本和导出。
- 提供运营方可注册发布、客户配合和合作投稿三类渠道建议，不自动发布。
- 渠道推荐会回写到每篇内容简报，支持从正式 Web 生成并检查各平台适配版本。
- 区分 DeepSeek、通义千问 API 样本与豆包、元宝、Kimi 等消费者端人工样本。
- 监测品牌发现、正确关联、推荐、事实准确、来源覆盖和重复出现，并把问题转为优化任务。
- 监测批次支持选择全部 P0/P1 国内主流平台、仅核心 P0 或逐个平台选择；P1 消费者平台会生成待人工采样任务。

## 本次加固

- 66 个 API 操作与 OpenAPI 契约自动比对。
- 生产 HTTPS 入口、安全响应头、最小权限容器和版本化镜像。
- DeepSeek、通义千问密钥加密保存，不在页面、日志和接口响应中回显。
- PostgreSQL 与业务文件每日加密备份、每周保留、可选主机外复制。
- 隔离恢复会验证密文、归档、数据库计数、Schema 和逐文件 SHA-256。
- 十万条监测样本统计容量通过，修复大样本查询参数超过驱动上限的问题。
- Chromium 与 Microsoft Edge 的生产 HTTPS 登录和就绪检查通过。

## 发布边界

本候选版不包含自动发布、客户门户、多角色审批、第三方平台账号密码托管或“保证被 AI 收录/推荐”的承诺。生产部署、域名、云资源和付费模型调用仍需产品负责人单独批准。
