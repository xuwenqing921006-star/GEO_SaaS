# V0.1.0 已知限制

- 仅面向一个平台运营负责人，没有客户登录、多角色、审批流和组织权限。
- 聚焦中小型本地服务企业；复杂电商、跨国、多品牌集团和强监管行业尚无专用流程。
- 自动发布当前覆盖头条号、百家号、网易号和搜狐号，采用本机隔离浏览器会话；首次登录、验证码、安全验证、实名认证和平台风控仍需运营人员处理。
- GEO 自动监测当前只覆盖 DeepSeek、通义千问与豆包官方模型 API；API 样本不等同于消费者端 App 的完整回答。
- 每个平台最多五个发布账号；发布前必须先生成对应平台的渠道版本。
- 百家号、网易号和搜狐号适配器已实现通用发布闭环，但仍需使用真实运营账号逐平台验收当前页面结构。
- 本版本不开发客户结果报告。
- API 回答不能代表同名消费者应用的真实回答，系统会分开显示与统计。
- 平台可以提高企业信息的一致性、可引用性和公开来源覆盖，但不能保证任何搜索引擎或 AI 平台收录、展示或推荐。
- 渠道政策、费用和可抓取性会变化，正式发布前仍需通过官方入口复核。
- V0.1.0 提供单机 Docker Compose 可部署包，尚未执行生产云部署，也没有多机高可用和自动弹性扩容。
- 备份默认保存在主机加密卷；主机外副本需要运维人员另行配置 rclone 目标和凭据。
- 生产首次部署需要运维人员创建唯一负责人账号、配置 HTTPS 域名、模型密钥和强数据库密码。
