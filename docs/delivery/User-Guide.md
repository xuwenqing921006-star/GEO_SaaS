# GEO SaaS 负责人使用指南

## 1. 建立客户

登录后进入“客户工作台”，新建本地服务客户并填写标准名称、行业、所在地区、地址、服务范围、营业信息和联系方式。标准名称、地区和核心服务将贯穿后续内容与监测，建议使用工商或对外长期统一使用的名称。

## 2. 完善企业知识库

先下载简版客户资料模板，由客户填写企业名称、地区、行业、服务、优势、经营信息和联系方式等常用资料，再上传到系统。也可以直接在页面新增、编辑或删除知识条目。录入知识库的内容默认是可用于 GEO 分析和文章生成的信息，不再单独处理授权、审核、证据、冲突或禁用状态；资料发生变化时直接更新对应条目即可。

## 3. 生成 GEO 诊断

进入“GEO 诊断”，生成当前客户的实体清晰度、证据、内容、来源和可见性诊断。先处理阻断项，再进入关键词与内容计划。

## 4. 确认问题与关键词

系统会结合企业资料、地区和行业生成五类目标问题：品类发现、推荐决策、场景咨询、选择比较和品牌核验。检查问题是否符合真实客户表达，锁定准备使用的问题和关键词。

## 5. AI 生成文章

在“内容工作台”选择内容简报并点击 AI 生成。系统会组合企业知识条目、目标问题、关键词、渠道要求和自然表达规则生成首稿；人工不需要从空白开始写，只在生成后编辑。内容简报会显示当前建议渠道；文章完成后可点击“生成渠道版本”，由 AI 分别调整标题、导语、结构与篇幅，并再次执行事实与质量检查。

生成完成后，“渠道成品”区域会按知乎、百家号、今日头条等目标平台分别展示成品标题、正文预览、版本号和质量状态。点击“编辑此版本”可把任意渠道成品载入编辑器，修改标题或正文并保存为该渠道的新版本。每个平台版本都可以单独导出 Markdown 或 DOCX，导出的文件会标明本次适配渠道，避免误把同一篇内容原样投放到所有平台。

导出前重点检查：

- 企业名称、地址、服务范围和联系方式是否准确；
- 是否出现未确认的价格、效果、资质或承诺；
- 标题和正文是否自然回答目标问题；
- 是否包含清晰、可摘取的企业实体信息；
- 文章是否适合所选渠道，而不是同一版本到处复制。

标题与正文共用同一套事实和质量检查。即使问题只出现在标题中，例如资料中没有的成立年份、人员规模、效果承诺或“最佳”等绝对化表达，系统也会阻止导出；需要先修改文章或补充准确的知识条目。

## 6. 选择发布渠道

“渠道建议”会区分运营方可注册发布、需要客户主体配合和第三方合作渠道，并显示官方入口、费用属性、风险和改写要求。生成或刷新渠道建议后，每篇简报最匹配的运营方渠道会自动同步到内容工作台，用于生成渠道适配版本。平台不保存第三方账号密码，也不会自动发布；发布后按渠道规则人工操作。

## 7. 监测 AI 可见性

“AI 可见性监测”包含两类样本：

- DeepSeek、通义千问 API 样本：适合持续、可重复跟踪；
- 豆包、腾讯元宝、Kimi、百度 AI 搜索/文心、夸克 AI、微信 AI 搜索、抖音 AI 搜、纳米 AI 搜等消费者端样本：在对应官方应用提问后，把完整回答粘贴回系统。

开始一轮监测前可选择全部 P0/P1 主流平台、仅核心 P0，或逐个平台勾选。被选中的消费者平台会生成待人工采样任务。系统会分别统计品牌是否出现、是否与地区和服务正确关联、是否形成推荐、事实是否准确以及是否显示来源。消费者端与 API 结果不会混算；一次未出现不等于平台永久未收录。

## 8. 配置模型

在“系统设置”中配置 DeepSeek 和通义千问 API Key，先验证连接，再启用模型。页面只显示配置状态和末尾掩码，不会回显完整密钥。建议千问用于主写、DeepSeek 用于复核，并设置每日预算上限。

## 9. 推荐的日常节奏

每周补充或更新客户资料；按内容计划生成、校对和发布；每两到四周用相同核心问题复测；把未出现、关联错误或推荐依据不足的结果加入下一轮优化任务。GEO 是持续建立公开可信信息的过程，不是一次发布即可完成。
