# T-016 全站明亮视觉与弹窗体验重构

## 变更目标

在不改变 GEO 业务流程、接口与数据的前提下，把当前偏阴暗、偏工程化的界面升级为适合单人代运营工作台的明亮视觉系统，并统一所有弹窗体验。

## 影响用户

- 平台唯一运营负责人
- 不新增客户登录、角色、审核或发布流程

## 范围

- 全站色彩令牌、页面背景、侧栏、顶栏、卡片、表格、表单和按钮
- 客户工作台、知识库、诊断、策略、内容、渠道、监测、设置与登录页
- 所有 `ModalDialog` 弹窗的遮罩、宽度、标题区、正文区、操作区、滚动与键盘关闭
- “证据与授权”弹窗的信息分组与操作层级
- 1440、1280、1024 桌面宽度的视觉与可用性回归

## 非范围

- 不改变任何后端接口、业务判断、数据结构或模型调用
- 不新增深色模式
- 不执行生产部署

## 视觉方向

- 主工作区：雾白背景与纯白内容面板
- 导航：白色侧栏，浅蓝色选中态，蓝色 SVG 图标与定位 Logo
- 强调色：明亮蓝色用于主按钮、链接、图标、筛选选中态和键盘焦点
- 状态色：绿色、琥珀色、珊瑚红分别承担通过、提醒与阻断，避免和蓝色操作混用
- 阴影：低对比柔和阴影，避免大面积灰黑遮罩
- 弹窗：卡片化、内容紧凑、标题与操作固定、正文独立滚动

## 验收标准

1. 全部业务页面不再使用大面积深绿色作为主背景，侧栏和工作区整体明亮。
2. 所有弹窗具有统一的圆角、阴影、正文内边距、操作区和关闭体验。
3. “证据与授权”弹窗首屏能够清楚看到事实内容、状态、主操作和证据，不出现大块无意义空白。
4. 长表单弹窗可在视口内滚动，标题和底部操作保持可用。
5. 页面在 1440、1280、1024 宽度无横向溢出，文字对比度与键盘焦点清晰。
6. 原有单元测试、类型检查、构建和关键浏览器旅程继续通过。

## 回滚

本变更只涉及前端样式与弹窗展示组件，可通过移除新增主题样式并恢复弹窗组件模板回滚，不涉及数据迁移。
