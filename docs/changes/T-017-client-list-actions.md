# T-017 客户列表与任务操作融合

## 变更目标

移除客户工作台右侧独立的“下一步”面板，把资料进度、当前 L 级、阻断和下一步任务直接整合到客户列表，并为每个客户提供清晰的查看、编辑和删除操作。

## 用户与场景

- 用户：平台唯一运营负责人。
- 场景：在客户工作台快速判断每个客户的当前进度、优先任务，并直接查看、编辑或删除客户。

## 范围

- 客户列表调整为“客户 / GEO 进度 / 当前任务 / 状态与更新 / 操作”。
- 每行展示资料完整度、当前级别、下一目标、阻断数量和下一步任务。
- “查看”打开客户概览。
- “编辑”打开客户资料编辑弹窗。
- “删除”采用现有归档能力实现可恢复软删除，并二次确认。
- 已删除客户在“归档”筛选中可恢复。
- 下一步任务可直接跳转到对应工作区。
- 左侧主导航固定在视口中，右侧页面滚动时导航位置不变。

## 非范围

- 不新增永久删除接口。
- 不删除客户历史文章、知识库、监测样本或文件。
- 不改变客户、内容、模型或监测的数据结构。
- 不执行生产部署。

## 验收标准

1. 右侧独立下一步面板消失，任务信息只在客户列表中展示。
2. 每个客户行同时展示资料完整度、L 级、阻断和下一步任务。
3. 操作栏包含查看、编辑、删除；已归档客户显示查看和恢复。
4. 查看弹窗能看清企业、地区、状态、进度和下一步。
5. 编辑弹窗可修改客户资料并保存，未保存离开仍有保护。
6. 删除弹窗明确说明是可恢复删除，确认后客户进入归档状态。
7. 1024、1280、1440 宽度可用且无页面级横向溢出。
8. 页面纵向滚动后左侧 Logo 和主导航仍固定在视口顶部。

## 回滚

本变更只复用现有客户查询、更新、归档和恢复接口，可恢复旧列表与右侧面板，不涉及数据库迁移。
