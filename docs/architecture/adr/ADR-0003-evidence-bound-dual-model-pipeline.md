# ADR-0003：证据约束的双模型内容流水线

Status: Accepted  
Date: 2026-07-27

## Context

产品价值取决于内容既利于实体理解与引用，又不编造客户事实或呈现明显 AI 腔。单模型自检容易重复自己的错误，直接自由写作难以追溯。

## Decision

内容任务先冻结已确认事实与授权证据。千问 `qwen3.7-plus` 非思考模式负责结构化提取、提纲和主稿，DeepSeek `deepseek-v4-pro` 用独立提示词检查。自然化只能调整表达，之后再次执行事实检查。阻断项必须人工处理。

`deepseek-v4-flash` 是千问故障时的主写降级；DeepSeek Pro 故障时由千问使用独立复核模板降级。每次调用保存精确模型、模板、事实快照、用量与降级原因。

## Consequences

- 事实可追溯，单模型盲点降低。
- 成本与时延高于单次生成，需要日预算、按步骤缓存和人工触发。
- 双模型一致不等于事实正确，最终权威仍是已确认事实与证据。

## Revisit when

金标集显示另一组合在事实准确、人工修改量和成本上持续优于当前组合，且完成回归和产品批准。
